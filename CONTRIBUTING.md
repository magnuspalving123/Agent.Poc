# Contributing

This repository follows the BOS guidance from **PR creation and structuring**. Keep changes aligned with the documented practices below.

## Kodestandarder og navngiving

Use clear, consistent names for files, symbols, branches, and PR content. Follow the repository's existing conventions where they already exist, and keep naming readable and purpose-driven. The BOS source **PR creation and structuring** also points to using code standards and naming conventions as part of well-structured pull requests.

## Commits

Keep commits clean, meaningful, and atomic. Prefer small commits that each represent one logical change. This matches the BOS source **PR creation and structuring**, which emphasizes clean and atomic commits.

## PR-struktur

Pull requests should be small and focused. Use a draft PR when the work is not ready for review. Give the PR a clear title and a description that explains the change and its intent. These practices come from the BOS source **PR creation and structuring**.
